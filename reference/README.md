# Polform S.r.l. — Documentazione Strategica, Analisi di Mercato & Design System

Benvenuti nella cartella documentale (`reference/`) del progetto di rilancio industriale e transizione digitale per **Polform S.r.l.** (Matera).

Questa suite documentale raccoglie tutte le evidenze raccolte tramite analisi di mercato, intelligence competitiva, benchmark di design system e strategie industriali volte a superare la crisi strutturale del mobile imbottito murgiano.
